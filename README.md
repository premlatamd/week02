
# SVD Image Compression

This project demonstrates image compression using Singular Value Decomposition (SVD).

## Files

- project2_svd.ipynb : Jupyter notebook containing the implementation.
- REPORT.md : Detailed analysis, results, and discussion.
- images/ : Source images used in the experiments.

## How to Run

1. Open `project2_svd.ipynb`.
2. Install required libraries:

```bash
pip install numpy matplotlib pillow requests
```

3. Run all notebook cells.
4. The notebook generates:
   - SVD reconstructions
   - Compression measurements
   - Singular value plots
   - Noise analysis
